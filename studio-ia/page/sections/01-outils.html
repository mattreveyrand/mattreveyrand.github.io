Plan 02

Claude, Claude Code, Cowork : qui fait quoi

Les trois utilisent les mêmes modèles et le même abonnement. Ils diffèrent par ce qu'ils peuvent toucher : une conversation, tes fichiers et ton terminal, ou tes dossiers de bureau. Choisir le bon évite de payer des tokens pour faire faire à un outil le travail d'un autre.

claude.ai · desktop · mobile

Claude, l'app

Pour : penser, écrire, analyser un document, chercher sur le web, publier une page.

  • Projets : des consignes et des fichiers de référence partagés par toutes les conversations d'un même chantier.
  • Mémoire : Claude retient tes préférences d'une conversation à l'autre (Réglages → Mémoire ; le mode incognito la coupe).
  • Connecteurs : Higgsfield, Drive, Gmail… branchés en MCP.
  • Skills et artefacts (voir plus bas).
terminal · desktop · web · IDE

Claude Code

Pour : tout ce qui lit ou écrit des fichiers et lance des commandes.

  • Scripts ffmpeg, HyperFrames, sites, pipelines, dépôts Git.
  • CLAUDE.md, skills, sous-agents, hooks, plugins, MCP.
  • Mode plan (Shift+Tab), retour arrière (Esc Esc ou /rewind).
  • Sessions cloud sur claude.ai/code, tâches planifiées, pilotage depuis le téléphone.
desktop · web · mobile

Cowork

Pour : déléguer un travail de bureau long, sans code. Les tâches tournent sur les serveurs d'Anthropic : tu peux fermer l'ordinateur et suivre depuis le téléphone.

  • Trier et renommer des rushes, remplir un tableur de plans, préparer un rapport ou une présentation.
  • Plugins par métier et skills partagés avec l'app.
  • Tâches planifiées et récurrentes.
  • Deux modes : manuel (tu valides chaque action) ou automatique (avec garde-fous).

Quel outil pour quelle tâche

TâcheOutilPourquoi
Écrire un script, un découpage, une note d'intentionClaude, dans un ProjetLes consignes et références du Projet sont déjà chargées.
Générer une image ou une vidéo Higgsfield en discutantClaude + connecteur HiggsfieldLe widget d'upload et le lecteur de résultats ne s'affichent que dans l'app.

Partager un moodboard, une fiche, un outilUn artefactUne page hébergée, privée par défaut, avec un lien.

Installer Claude Code

macOS · Linux · WSL
curl -fsSL https://claude.ai/install.sh | bash
