Le pack : ce qu'il faut installer, et ce qu'il faut éviter

Recherche du 28 septembre 2026 : dépôts vérifiés un par un, tests indépendants quand ils existent. Les chiffres annoncés par les auteurs sont souvent 2 à 8 fois supérieurs à ce que mesurent les tests indépendants, et parfois de signe contraire (RTK). Règle : installer un outil à la fois, et regarder /usage pendant une semaine avant d'ajouter le suivant. Sous Windows, vérifier d'abord que node (Ponytail, caveman, Context7) et python (planning-with-files, dont les hooks sont lents sans lui) répondent dans Git Bash.

Déjà là, gratuit, à utiliser d'abord

Réglage ou commandeCe que ça apporte
/usageSur Pro et Max : part de la consommation attribuée à chaque skill, plugin, sous-agent et serveur MCP. C'est l'outil pour juger tout le reste ; il ne compte que l'historique de Claude Code sur cette machine (ni claude.ai, ni tes autres appareils).
/context, /doctorCe qui remplit la fenêtre ; coût de la liste des skills et plus gros contributeurs.
Mémoire autoActive par défaut. Index MEMORY.md dont les 200 premières lignes (25 Ko max) sont chargées à chaque session ; fiches thématiques lues à la demande.
Budget de la liste des skillsNoms et descriptions de tous les skills tiennent dans environ 1 % de la fenêtre. Au-delà, des descriptions sont retirées et les skills se déclenchent mal. Pour tes skills personnels ou de projet rarement utiles : mode « nom seul » (skillOverrides) ou disable-model-invocation: true pour ceux que tu appelles toujours à la main. Les skills livrés par un plugin ne sont pas concernés : on les gère avec /plugin (désactiver le plugin). /skill-doctor liste ceux qui ne servent jamais.
Sous-agents sur un petit modèlemodel: haiku dans la définition d'un sous-agent qui fait du tri, de la lecture de logs, du renommage.
/effortBaisse la réflexion pour les tâches de routine (elle ne se coupe pas complètement sur Opus 5.5).

Pour le code, jamais pour l'écriture
context-mode
mksglu		 Fait passer les grosses sorties (pages web, logs, Playwright) par un bac à sable ; seul le résultat entre dans le contexte. Chiffres de l'auteur uniquement. Ajoute beaucoup de hooks. /plugin marketplace add mksglu/context-mode
/plugin install context-mode@context-mode		 Sessions web lourdes

Un seul cadre de travail : Superpowers ou compound-engineering ou GSD Core. Les empiler multiplie les hooks, les skills et les tokens.

Les plugins « Pour le code » (Superpowers, Ponytail, caveman) se chargent sinon dans toutes tes sessions, vidéo comprises : Ponytail s'active en mode full à chaque session et s'injecte aussi dans chaque sous-agent. Dans une session, /plugin install ouvre un panneau qui demande la portée : lance-le depuis chaque dépôt de code et choisis « Install for you, in this repo only » (portée locale).

À éviter

OutilPourquoiVerdict
claude-memSon « observateur » en arrière-plan résume chaque appel d'outil avec un LLM : sur ton forfait Anthropic, ou sur le service hébergé de claude-mem que l'installateur pousse à activer (tes transcripts partent chez eux ; après 30 jours d'essai, retour sur ton forfait sans abonnement). Un ticket ouvert le 13 septembre 2026 (#4070) mesure l'observateur à 43 % du trafic de tokens observé (7,9 M en 4 h, surtout de l'écriture de cache). La mémoire auto intégrée couvre l'essentiel.Éviter
RTK et hooks de compression BashRéduit « jusqu'à 90 % » de la sortie Bash lue par l'agent, ce qui n'est pas 90 % de la facture, précise son propre README ; mesuré +7,6 % de coût médian par tâche à effort bas et neutre (+0,1 %) à effort haut (JetBrains). Les outils Read, Grep et Glob de Claude Code passent à côté du hook. À garder seulement si /usage montre un gain sur ton travail.Mesurer d'abord
Routeurs d'abonnement (OmniRoute, 9router, sub2api, CLIProxyAPI…)La connexion Free, Pro ou Max est réservée à l'usage ordinaire de Claude Code et des applications d'Anthropic ; faire transiter ou mutualiser ces identifiants par un outil tiers est interdit, et Anthropic peut sanctionner sans préavis. Risque de blocage du compte. (free-claude-code, lui, ne te donne pas Claude : il branche Claude Code sur d'autres modèles, NVIDIA NIM et autres, et ton code part chez ces fournisseurs.)Interdit
Méga-paquets (ECC, gstack)ECC (292 skills, 68 agents, 94 commandes) déborde à lui seul du budget de 1 % de la liste des skills, et les déclenchements se dégradent ; gstack (23 rôles et 8 outils en commandes) impose un flux complet qui recoupe Superpowers. Prendre un skill à la fois si besoin.Éviter
claude-context (Zilliz), mem0, Graphiti, LettaTon code part vers des services d'embedding, ou c'est de l'infrastructure pour construire ses propres agents.Hors sujet
BMAD, SuperClaude, spec-kitCérémonie lourde pour un créateur solo ; recoupent Superpowers.Éviter
Sécurité Un audit de Snyk (février 2026) sur 3 984 skills publiés sur ClawHub et skills.sh a trouvé au moins un problème de sécurité critique dans 13,4 % d'entre eux (534 skills). Avant d'activer un plugin : lire son SKILL.md et son hooks/hooks.json, préférer la marketplace officielle (Anthropic y précise qu'il ne contrôle pas le contenu des plugins tiers, comme Superpowers ou Context7), puis vérifier /hooks et /mcp après l'installation.
